# Basic operation

## Explanation of terms

| Term               | Explanation                                                                                                                                                                                                                                                                                                                                                                          |
| ------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Virtual exhibition | A virtual exhibition is the core concept of the system and its resulting product. It is a coherent presentation of a particular subject, created using visual, textual and audiovisual information and interaction. INDIHU Exhibition software is called the exhibition editor.                                                                                                      |
| Editor             | The editor is the INDIHU Exhibition tool in which a creator builds an exhibition. The editor runs in a web browser.                                                                                                                                                                                                                                                                  |
| Creator            | A creator is a person who creates an exhibition.                                                                                                                                                                                                                                                                                                                                     |
| Visitor            | A "visitor" is a user who visits a virtual exhibition website.                                                                                                                                                                                                                                                                                                                       |

| Chapter            | Screens can be grouped into chapters. Creating chapters is a tool for logically structuring content. An exhibition can contain one or more chapters. A chapter always includes a chapter introduction screen with a title and cover image, which may be animated. When viewing an exhibition, visitors can jump from one chapter to another through the "Chapters" list in the menu. |
| Game               | To provide the greater interactivity that visitors expect today, [games](hry.md) are available. ## Creating an account

1. **Creator registration**: To use INDIHU Exhibition as a web application, you need to register at [exhibition.indihu.cz](https://exhibition.indihu.cz). You can create registration details and choose a login (email address) and password, or use your Google, Facebook or GitHub login to register. After completing the registration form, confirm your registration using the link sent to the email address provided. This creates an account request, which is approved by an administrator within 3 days at the latest. Once the request is approved, a user account with the Editor role is created. The applicant is kept informed of the registration process by email notifications.
2. **Logging in to the editor**: The creator logs in with the username (email address) and password chosen during registration, or through the third-party Google, Facebook or GitHub service. In the "Account management" tab on the right-hand side of the header, the creator can change their personal details or password, or delete their account.

## Can we prepare an exhibition ourselves?

Creating (virtual) exhibitions is teamwork. However, you do not need to be able to program or be web designers to create an online exhibition. The editor allows multiple creators to collaborate on an exhibition. It does not allow real-time collaboration: only one creator can make changes at a time, and the editor unlocks for co-creators after 1 minute. The editor is designed to make it **as easy to use as possible**.

The [Creating a successful exhibition](uspesna-vystava.md) section offers tips for creators making their first exhibition as well as those with more experience who want to develop their skills and try new features.

!!! info "Tip"
    Work as a team. Although the editing lock is set to only 1 minute, agree in advance who will work on the exhibition and when. This prevents you from working on the same part of the exhibition.

Virtual exhibitions contain different types of content that you create outside the editor using other tools, then insert into the editor. It is therefore useful if you can:

- Work with images at least to some extent
- Record audio or prepare materials for recording
- Create videos or write a script and commission someone to produce the video

!!! info "Tip"
    If you notice an **error** in text or images after publishing an exhibition, do not worry, you can correct it. **The exhibition can be edited** even in Published mode, or you can change its status to In preparation if the change will take longer. Changes are saved immediately and visitors always see the most up-to-date version.

### Simple image editor

Modern web presentations increasingly depend on the use of images. You therefore cannot avoid working with images when preparing exhibitions. Of course, you can prepare images in the tools you normally use. However, INDIHU Exhibition also includes a simple **image editor** that lets you make basic adjustments such as cropping, rotating or changing the aspect ratio.

!!! warning "Warning"
    **Copyright** is very complex online, and once you publish something online, anyone can download the images. We recommend using only images for which your institution holds the rights or which you took yourself. If you need illustrative images, use databases and images under a CC (Creative Commons) licence. We can recommend, for example, [Wikimedia Commons](https://commons.wikimedia.org/wiki/Main_Page) and [The Flickr Commons Program](https://www.flickr.com/commons). Audio and sounds are also available under CC licences. **Always state the source** of images or other media. You can use a text field or infopoint for this.

You can find it under the palette icon on the image itself or in Files. If your resources allow, you can **use professional services** (a photographer, graphic designer, filmmaker or sound engineer).

## After entering the editor

After logging in to the editor, you see the **list of exhibitions**. These exhibitions were either created by the creator or the creator received viewing or editing permission from another user. Exhibitions are divided according to the permissions you have:

- I am the author
- Shared for reading
- Shared for writing (you are a co-creator)

Exhibitions are displayed graphically as **tiles** or as a **list** (see images). Use the icon in the top-right corner (1) to switch views. Exhibitions can be **filtered** or sorted using the controls at the top of the window (Last used, Name, etc.) (2). The creator can also **search** the exhibition list by title (3).

Each exhibition shows basic information, including its title, owner, status and date of last modification (4).

For each exhibition, the three-dot button (5) provides basic actions such as renaming, sharing the exhibition or part of it, exporting, changing its status, copying or deleting it.

## Exhibition structure and basic settings

When opening exhibition details, the creator sees the first tab, "Exhibition structure" (1). They can switch to the "Files" tab (2) to manage exhibition files, "Settings and sharing" (3) for general settings for the whole exhibition, the "Ratings and visits" tab (4), where visitor statistics are visible, and the final "Theme" tab (5), which allows them, for example, to set colours and add their institution's logo to the exhibition.

After creating a new exhibition, it automatically contains the first screen, "Exhibition introduction" (6), the option to add a screen using the + icon (7), and the "Exhibition conclusion" screen (8).

![](../img/struktura-vystavy-popis.png)

All changes a creator makes in exhibition details are saved immediately; there is no Save button.

Every exhibition contains two compulsory parts: the Exhibition introduction screen and the Exhibition conclusion screen (see [Exhibition details](zaklady.md#exhibition-structure-and-basic-settings) above). Between them, the exhibition can be structured into chapters or assembled from individual screens. Each chapter must contain a chapter introduction screen, followed by additional content screens.

After adding a selected screen, add further screens using the + button (8). An exhibition is created by gradually adding more screens and assigning them to chapters.

### Exhibition files

Each exhibition has its own file repository, where the creator can upload files needed to create the exhibition. The creator can also create directory structures ("new directory") and move files between folders. Image previews and file metadata are available. Use the ... icon to access the individual image menu. The creator uses these files when creating and editing individual pages, so try to keep the files as well organised as possible. The editor also supports bulk uploads.

!!! info "Tip"
    Files can be kept organised in several ways. For example, arrange files in directories by chapter. Another option is to organise them by format: images, text and audio files separately. You may have several versions of the same image while preparing an exhibition, so we recommend naming your images. Delete unused files. Think in advance about how you will work with and name files, and follow the rules across the creative team.

### Settings and sharing

This tab contains all virtual exhibition settings relating to the exhibition as a whole: exhibition status, exhibition URL, exhibition embed code, exhibition tags and sharing with other creators.

![](../img/nastaveni-sdileni-popis.png)

**Exhibition status (1)**

- **In preparation**: The exhibition is being prepared. Its content can be edited freely. The exhibition is accessible only to logged-in creators with whom it has been shared.
- **Published**: The exhibition is publicly available at its URL. The exhibition cannot be edited.
- **Finished**: The exhibition has ended and is neither publicly available nor intended for further editing. The exhibition can be returned to "In preparation" or "Published" status.

**Exhibition URL (2)**

Lets you set any URL ending so that it is easy to use and remember.

!!! info "Tip"
    The exhibition URL lets you set any URL ending so that it is easy to use and remember. Adjust the URL so that it looks good on promotional materials.

**Exhibition embed code (3)**

This feature generates HTML embed code that you can insert into your own website, allowing visitors to browse the exhibition on your website. It works similarly to embedding a map or video from YouTube on your website.

**Exhibition tags (4)**

Exhibition tags appear on the exhibition landing page and help visitors decide whether an exhibition is right for them. Choose from the available tags:

- 1 main exhibition subject (e.g. History and People, Nature or Art)
- 2 formal characteristics of the exhibition (e.g. Educational, English-friendly or Entertaining)
- who the exhibition is intended for (e.g. Children, Professionals or Students)

!!! info "Tip"
    You can create several versions of an exhibition on the same subject for different target groups.

**Information for visitors when the exhibition has ended (5)**

It is great that visitors are interested in your exhibition, but you may no longer consider it current for any reason. Therefore, set information for cases where a visitor finds your exhibition but it is no longer available. Choose an image, enter a URL for redirection (for example, to your website, a current exhibition or another interesting online project) and write visitors a short message, such as thanks for their interest and information about new projects.

**Shared with users (6)**

An exhibition can be shared with other creators using their email addresses. Other creators can be given **read-only** or **read and write** permissions. If you add someone who is not a registered user, the system sends them an invitation to register. Co-creators are informed about exhibition sharing by email.

The exhibition can also be **shared by sending its URL**, whether a link to the title screen or to any chapter or screen. However, if the exhibition is not Published, nobody other than its other creators will see it.

When **multiple authors collaborate**, editing is automatically locked for 1 minute. Information about which creator is currently editing the exhibition is visible both in the exhibition list and in the exhibition details. Other creators can view the exhibition but not edit it.

!!! info "Tip"
    Although the editing lock is set to only 1 minute, we recommend agreeing in advance who will work on the exhibition and when. This prevents you from working on the same part of the exhibition.

## Ratings and visits

The "Ratings and visits" tab provides information about how visitors perceive the exhibition. It includes the total number of views, which the system counts automatically, similar to views on YouTube videos. This rating can provide useful feedback on what worked well and where there is room for improvement. A simplified rating is also shown in the list of all your exhibitions, so it is readily available.

![](../img/hodnoceni-vystavy.png)

![](../img/hodnoceni-vypis-dlazdice.png)

Visitors are invited to rate the exhibition on the final screen. The overall exhibition rating uses stars; visitors can then choose aspects of the exhibition (such as the subject or games) that particularly interested them. They can also leave the creators a message and an address to which they can reply. Leaving a message is optional.

![](../img/hodnoceni-vystavy-navstevnici-orez.png)

## Theme

The final tab in the exhibition's general settings is for adjusting the theme, or exhibition colour scheme. The editor offers two basic themes: **light** and **dark**. However, the editor lets you set some elements using **custom colours**. This is particularly useful if your institution has a unified graphic manual and corporate identity. In general settings, you can change the background colour, icon colour (such as arrows), and tag colour. In the "Logo and watermark settings" section, you can also upload your own logo and choose where it will appear. In the third section, you can change the general settings of infopoints, so that all infopoints use your selected colour. However, you can change the colour of each infopoint individually as needed, giving only some a different colour to highlight them more.

![](../img/motiv.png)

!!! warning "Warning"
    Do not forget to save theme changes in the bottom-right corner.
